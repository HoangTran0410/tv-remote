# Remote keys: give a key an app, fix dead keys, hold

Color keys, number keys and buttons that no longer do anything can open the app you choose. It needs [TV Home]; to work in every app it also needs TV Setup.

1. On the TV: the **⚙** icon at the top → **Quick settings** → **Customize** → **Quick keys & power-onup** → **Quick keys**. Phone or computer: the same name, in the **Quick keys & power-onup** card.
2. Pick a key's tile, then an app, a shortcut or a live widget. The first pick switches the keys on. Outside TV Home the TV says "TV Setup opened…", so it is not a fault.
3. In the **At power-on** tile pick an app, or **Last app used** (the one open when the TV turned off). It opens once per power-on, not if the TV woke into another app. One choice turns the other off.
4. In the same card, **Double press and hold**: each color key, the YouTube / Netflix / Prime buttons, Menu, Info and Guide can open an app or shortcut (a scene too) on a double press or a 0.6 s hold. A key with a double press waits 0.3 s for a second press; a key without one stays instant. A key with a hold acts when you let go. Not for Home, Back, the arrows, OK, volume or the number keys. Needs the newest TV Setup; a key with no action of its own needs ADB to give back its plain press.

| Key | When it can be given an app |
| --- | --- |
| Red, green, yellow, blue | Always: no app uses them |
| 0-9 | On TV Home: a press. In other apps: hold 2 s (needs TV Setup) |
| YouTube, Netflix, Prime Video | Always: given another app, the button opens it instead (needs TV Setup) |
| TV, Input, PatchWall, All apps, Settings | Only while the button is dead. A working button is never taken |
| Voice command (in the list, next to apps) | For a color or app key when the system keeps the Assistant button (Xiaomi). Needs TV Setup 0.46.1+ |

> 💡 A greyed tile saying "not on this remote": this remote has no such key. Without TV Setup the keys work on TV Home's own screen only.

> 💡 Dead buttons, hold-to-use and the TV Setup Keys add-on: see [Fix dead keys, hold to switch].

### Tips

- An app's tile shows its key in the top corner (a colour dot, a number or an icon); hidden when quick keys are off.
- Quick keys use the same keypad: see [Quick keys].
